# 👁️ Affordable Distraction Detection System
*Practical AI for Real World Safety & Loss Prevention*

## 📌 The "Why" Behind This Project
Most AI safety tools fail because they require $1,000+ hardware to work. This project flips the script. I've built a **Loss Prevention** solution designed to run on standard equipment—proving that safety shouldn't be a luxury. The focus here is on **market viability** and solving the "last mile" of technical implementation where lab models usually break.

## 🚀 Business & Strategic Moat
- **Loss Prevention over Features**: We aren't just detecting eyes; we’re mitigating the massive financial and human cost of fatigue related accidents.
- **Mid Market Strategy**: Positioned for logistics and transport fleets that need scalable safety without the "enterprise" price tag.
- **Burn Rate Efficiency**: Software first approach that keeps infrastructure costs low and deployment speed high.

## 🛠️ The Tech Stack
- **Framework**: Teachable Machine (TensorFlow-backed) via Keras.
- **Core Engine**: Python (Inference) & JavaScript (Web view).
- **Stress Testing**: Trained on raw, non perfect datasets including head tilts, varying lighting, and even "the headset test" to find exactly where the model starts to hallucinate or fail.

## ⚙️ The PM’s Reality Check (For Tech Leads)
I’ll take a responsive "lean" model over a 99.9% accurate "slow" model any day. Our focus is:
- **Performance Budgeting**: Low latency is non negotiable for real time safety. We optimized for responsiveness over pure lab metrics.
- **Handling the "Edge"**: I’ve documented the model’s blind spots low light environments, eyewear interference, and lens blur. As a PM, I’d rather manage these known risks than ignore them.
